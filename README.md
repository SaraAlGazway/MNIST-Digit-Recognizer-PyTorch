## 📋 Overview

This project implements an **UltimateCNN** for the [Kaggle Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer) competition (MNIST dataset).

| Property | Value |
|----------|-------|
| **Dataset** | MNIST (42,000 train + 28,000 test) |
| **Model** | UltimateCNN (Conv + BN + Dropout) |
| **Framework** | PyTorch |
| **Test Accuracy** | **99.36%** ✅ |
| **Parameters** | 468,458 |
